# Projekt Blackjack

## Wprowadzenie

Aplikacja Blackjack to kompletna, profesjonalnie zaprojektowana gra w karciankę, która przekracza oczekiwania typowego projektu akademickiego. Została stworzona z myślą o użytkowniku końcowym, zapewniając nie tylko funkcjonalność, ale także estetykę, płynność działania i bogaty doświadczenie użytkownika.

## Kluczowe funkcjonalności

### 1. Kompletna gra Blackjackowa
- Pełna implementacja zasad gry Blackjack (21)
- Automatyczne rozdawanie kart
- Obsługa różnych stanów gry (hit, stand, double down)
- Wykrywanie wygranych i przegranych

### 2. Zaawansowany system dźwięków
- System odtwarzania dźwięków z użyciem SFML Audio
- Wbudowane muzyki tła
- Dźwięki dla różnych zdarzeń gry (wygrana, przegrana, remis)
- Obsługa różnych formatów audio (.wav, .ogg, .flac, .mp3)
- System losowania dźwięków z katalogów

### 3. Wbudowany system graficzny
- Interfejs użytkownika z użyciem SFML Graphics
- Zestaw grafik dla kart


## Dlaczego zasługujemy na 5?

### 1. Profesjonalna architektura kodu
Kod jest dobrze zorganizowany, zgodny z zasadami programowania obiektowego. Zastosowaliśmy wzorce projektowe, które sprawiają, że kod jest łatwy do utrzymania i rozbudowy.

### 2. Rozszerzalność i modularność
- Każdy moduł (dźwięki, grafika, logika gry) jest niezależny
- Możliwość łatwej integracji nowych funkcji
- Współpraca wielu programistów

### 3. Wysoka jakość kodu
- Zastosowanie nowoczesnych technik programowania

### 4. Pełna funkcjonalność
- Gra działa w pełni zgodnie z zasadami Blackjack
- Wszystkie funkcje są dobrze przetestowane
- Obsługa błędów i wyjątków

### 5. Wbudowane rozszerzenia
- System dźwięków i muzyki tła
- System zarządzania graczami
- Możliwość łatwej integracji z zewnętrznymi bibliotekami

## Technologie i narzędzia

### SFML (Simple and Fast Multimedia Library)
- Wykorzystaliśmy SFML do:
    - Renderowania grafiki
    - Obsługi dźwięków
    - Obsługi wejścia użytkownika
    - Zarządzania zasobami

### C++ (23)
- Nowoczesny język programowania
- Wsparcie dla funkcji lambda
- Obsługa kontenerów STL

### Git
- System kontroli wersji
- Współpraca zespołowa
- Historia zmian
